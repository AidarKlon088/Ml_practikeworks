## Содержание

### PR10. Кластеризация и сегментация данных

Сегментация 600 клиентов магазина без меток.

- **Уровень A** — K-Means на 4 кластера и описание сегментов.
- **Уровень B** — выбор числа кластеров по методу локтя и силуэту, профили сегментов, проверка устойчивости.
- **Уровень C** — сравнение K-Means, DBSCAN и иерархической кластеризации на данных сложной формы, дендрограмма.

## Как запустить

**1.** Установить Python 3.11 или новее.

**2.** Установить необходимые библиотеки:

```bash
pip install pandas numpy matplotlib scipy scikit-learn jupyter
```

**3.** Открыть репозиторий в VS Code или Jupyter Notebook.

**4.** Открыть нужный ноутбук и выполнить все ячейки через **Restart & Run All**.
