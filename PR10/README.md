# Практическая работа №10 — Кластеризация и сегментация данных

**Тема:** Обучение без учителя: K-Means, DBSCAN, иерархическая кластеризация  
**Датасет:** `customers.csv` — 600 клиентов магазина (без меток)  
**Библиотеки:** Pandas, NumPy, Matplotlib, SciPy, Scikit-learn

## О проекте

Я разделил клиентов магазина на сегменты без заранее известных меток, выбрал число кластеров по нескольким критериям и сравнил три метода кластеризации на данных сложной формы.

## Файлы

| Файл | Что внутри |
|---|---|
| `pr10_A.ipynb` | Уровень A — K-Means на 4 кластера, график и описание сегментов |
| `pr10_B.ipynb` | Уровень B — метод локтя, силуэт, выбор k, профили и проверка устойчивости |
| `pr10_C.ipynb` | Уровень C — сравнение K-Means, DBSCAN и иерархической кластеризации |
| `customers.csv` | Данные о клиентах |
| `figs/` | Сохранённые графики |

## Основной код

| Код | Что делает |
|---|---|
| `StandardScaler()` | Приводит признаки к одному масштабу |
| `KMeans()` | Делит данные на k кластеров вокруг центров |
| `inertia_` | Инерция для метода локтя |
| `silhouette_score()` | Коэффициент силуэта |
| `adjusted_rand_score()` | Сравнивает два разбиения (ARI) |
| `DBSCAN()` | Кластеризация по плотности с выделением шума |
| `NearestNeighbors()` | График k-расстояний для подбора `eps` |
| `AgglomerativeClustering()` | Иерархическая кластеризация |
| `linkage()`, `dendrogram()` | Построение дендрограммы |

## Что я сделал

**Уровень A.** Отмасштабировал признаки, обучил K-Means с k = 4, построил график и таблицу средних значений по кластерам, описал каждый кластер.

**Уровень B.** Построил метод локтя и силуэт для k от 2 до 10. Оба критерия указывают на k = 3–4. Выбрал k = 4, потому что только так разделяются частые и редкие покупатели с большим чеком. Получил 4 сегмента:

| Кластер | Название | Клиентов |
|---|---|---|
| 0 | VIP-клиенты — большой чек, часто покупают, почти без скидок | 59 |
| 1 | Охотники за скидками — маленький чек, часто, 59% покупок по скидке | 220 |
| 2 | Спящие — редко покупают, не приходили ~3 месяца | 170 |
| 3 | Редкие крупные покупатели — большой чек, но покупают редко | 151 |

При других `random_state` состав кластеров не меняется (ARI = 1.0).

**Уровень C.** Сгенерировал данные, на которых K-Means работает плохо: два полумесяца, маленький плотный кластер и выбросы. Подобрал параметры DBSCAN по графику k-расстояний, построил дендрограммы и сравнил методы по силуэту, Davies–Bouldin и ARI.

| Метод | ARI |
|---|---|
| K-Means (k = 3) | 0.600 |
| DBSCAN по умолчанию | 0.374 |
| DBSCAN (eps = 0.2, min_samples = 4) | 0.996 |
| Иерархическая, ward | 0.622 |
| Иерархическая, single (срез 0.2) | 0.996 |

Лучше всего для таких данных подходит DBSCAN.
